## Apresentação

Este repositório reúne meus estudos, exercícios e atividades da disciplina de **Desenvolvimento em Python**, do curso de **Análise e Desenvolvimento de Sistemas da Universidade CEUMA**.

O objetivo é registrar minha evolução na programação, fortalecer o raciocínio lógico e aplicar os conteúdos estudados na resolução de problemas.

> Cada atividade representa uma etapa do aprendizado: compreender o problema, construir uma solução, testar e aprimorar.

## Como executar

### 1. Prepare o ambiente

Utilize uma instalação do **Python 3** e um editor de código de sua preferência.

### 2. Clone o repositório

```bash
git clone [https://github.com/vinisanths/Desenvolvimento-em-Python.git](https://github.com/vinisanths/Desenvolvimento-em-Python.git)
```

### 3. Acesse a pasta

```bash
cd Desenvolvimento-em-Python
```

### 4. Execute uma atividade

Substitua o caminho abaixo pelo caminho real do arquivo desejado:

```bash
python caminho/do/arquivo.py
```

Dependendo da configuração do ambiente, utilize:

```bash
python3 caminho/do/arquivo.py
```
